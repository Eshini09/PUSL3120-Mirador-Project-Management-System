# Mirador User Acceptance Testing Plan

## Participants

Use three participants or test personas:

- Administrator
- Project Manager
- Team Member

## Protocol

1. Give each participant a short role description.
2. Ask them to complete the task list without coaching.
3. Record whether they completed each task, where they hesitated and any usability comments.
4. Ask for a short satisfaction rating from 1 to 5.
5. Summarise changes made after the session.

## UAT Tasks

| ID | Role | Task | Success Criteria |
| --- | --- | --- | --- |
| UAT-01 | Admin | Create a project and assign a project manager | Project is saved with correct manager |
| UAT-02 | Admin | Add team members to the project | Members are visible on the project card |
| UAT-03 | Project Manager | Create and assign a task | Team member can see assigned task |
| UAT-04 | Project Manager | Create a milestone | Milestone appears in dashboard checkpoint list |
| UAT-05 | Team Member | Add a task comment | Comment appears on the task |
| UAT-06 | Team Member | Attempt to create a project | Access is denied |
